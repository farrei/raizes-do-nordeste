# Requisitos — Raízes do Nordeste

## Requisitos funcionais

| ID | Requisito |
|---|---|
| RF01 | Permitir cadastro e autenticação do cliente. |
| RF02 | Exibir cardápio conforme a unidade selecionada. |
| RF03 | Permitir montar a sacola e realizar um pedido. |
| RF04 | Permitir acompanhar o pedido pelos estados Recebido, Em preparo, Pronto e Retirada. |
| RF05 | Exibir saldo e benefícios do programa de fidelidade. |
| RF06 | Exibir promoções disponíveis. |
| RF07 | Encaminhar o pagamento para um serviço externo, representado no protótipo por uma simulação. |
| RF08 | Solicitar consentimento para o tratamento dos dados necessários ao pedido. |

## Requisitos não funcionais

- RNF01 — Interface responsiva e mobile-first.
- RNF02 — Navegação clara e consistente.
- RNF03 — Contraste e textos legíveis.
- RNF04 — Imagens com texto alternativo e carregamento otimizado.
- RNF05 — Estrutura simples, modular e de fácil manutenção.
- RNF06 — Estados de interação visíveis.
- RNF07 — O protótipo não armazena dados financeiros reais.

## Canais

- Web — implementado no protótipo.
- App — canal previsto no escopo funcional.
- Totem — canal previsto no escopo funcional.

## Atores

Cliente; Atendente; Cozinha; Gerente/Administrador; Sistema de pagamento externo.
