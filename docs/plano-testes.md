# Plano de testes

| ID | Cenário | Resultado esperado |
|---|---|---|
| T01 | Abrir a página inicial | Conteúdo e navegação aparecem corretamente. |
| T02 | Filtrar por Pratos | Somente pratos são exibidos. |
| T03 | Filtrar por Lanches | Somente lanches são exibidos. |
| T04 | Filtrar por Bebidas | Somente bebidas são exibidas. |
| T05 | Alterar unidade | Sistema informa a unidade selecionada. |
| T06 | Adicionar item | Item aparece na sacola e o contador é atualizado. |
| T07 | Adicionar item repetido | Quantidade do item é incrementada. |
| T08 | Remover item | Quantidade é reduzida ou item é removido. |
| T09 | Finalizar sacola vazia | Sistema impede a continuidade e informa o usuário. |
| T10 | Pagamento sem consentimento | Sistema impede o avanço e solicita consentimento. |
| T11 | Pagamento com consentimento | Pedido é confirmado e recebe identificador. |
| T12 | Responsividade | Layout se adapta a desktop e telas menores. |

## Critérios de aceitação

Cada teste deve ser executado em navegador atualizado, verificando também teclado, legibilidade, navegação e carregamento das imagens.
