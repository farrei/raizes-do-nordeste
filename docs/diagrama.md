# Diagrama do sistema

O diagrama de fluxo foi criado no Figma e representa os principais atores e integrações do protótipo.

**Fluxo principal:** Cliente → Cadastro/autenticação → Cardápio → Pedido → Pagamento externo → Acompanhamento.

Também são representados Cozinha, Atendente, Gerente/Administrador e o consentimento de privacidade/LGPD.
