# Jornada do usuário

1. **Primeiro contato** — o cliente acessa a plataforma e identifica a proposta da marca.
2. **Escolha da unidade** — seleciona a unidade desejada.
3. **Exploração** — consulta categorias, itens, preços e informações.
4. **Montagem do pedido** — adiciona produtos à sacola e ajusta quantidades.
5. **Pagamento** — segue para o fluxo de pagamento externo simulado.
6. **Confirmação** — recebe o número do pedido.
7. **Acompanhamento** — acompanha os estados: Recebido → Em preparo → Pronto → Retirada.
8. **Fidelização** — consulta pontos e benefícios após novos pedidos.

## Pontos de contato

Web é o canal implementado nesta entrega. App e Totem são canais considerados no escopo funcional.

## Privacidade

O fluxo de pagamento demonstra o consentimento necessário antes do encaminhamento para o serviço externo. O protótipo não solicita dados bancários reais.
