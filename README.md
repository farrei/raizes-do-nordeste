# Raízes do Nordeste

**Sabor que tem história.**

Projeto acadêmico desenvolvido por **EM TESTE**.

## Objetivo

Protótipo web responsivo para uma experiência digital de restaurante, contemplando cardápio por unidade, pedidos, acompanhamento, fidelidade, promoções, simulação de pagamento externo e privacidade/LGPD.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Estrutura

- `index.html` — interface principal
- `styles.css` — identidade visual, responsividade e efeito visual sutil
- `script.js` — interações e regras do protótipo
- `docs/requisitos.md` — RF/RNF e atores
- `docs/jornada.md` — jornada do usuário
- `docs/plano-testes.md` — 12 cenários de teste
- `docs/lgpd.md` — privacidade e consentimento
- `docs/diagrama.md` — referência do diagrama no Figma
- `.github/workflows/pages.yml` — publicação no GitHub Pages

## Fluxos demonstráveis

1. Seleção de unidade.
2. Filtros de cardápio.
3. Inclusão e remoção de itens da sacola.
4. Autenticação simulada.
5. Consentimento de privacidade.
6. Encaminhamento para pagamento externo simulado.
7. Retorno visual com pedido confirmado.
8. Fidelidade e promoções.
9. Acompanhamento do pedido.
