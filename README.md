# Raízes do Nordeste

**Sabor que tem história.**

Projeto acadêmico desenvolvido por **Rafael Ferreira Verissimo — RU 5000980**.

## Objetivo
Protótipo web responsivo para uma experiência digital de restaurante, contemplando cardápio por unidade, pedidos, acompanhamento, fidelidade, promoções, simulação de pagamento externo e privacidade/LGPD.

## Tecnologias
- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Estrutura
- `index.html` — interface principal
- `styles.css` — identidade visual e responsividade
- `script.js` — interações e regras do protótipo
- `docs/` — requisitos, jornada e plano de testes
- `.github/workflows/` — publicação no GitHub Pages

## Observação
O pagamento é apenas uma simulação acadêmica e não processa dados financeiros reais.
