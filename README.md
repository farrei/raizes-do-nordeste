# Raízes do Nordeste

Protótipo de interface front-end para uma rede de lanchonetes com unidades em Recife, Fortaleza e Salvador.

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)
![JS](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)

## Funcionalidades

- Cardápio filtrado por unidade
- Sacola com promoção (2 pratos = 1 suco grátis)
- Pagamento simulado
- Acompanhamento de status do pedido
- Programa de fidelidade (1 ponto por R$ 1)
- Consentimento LGPD explícito (Lei nº 13.709/2018)
